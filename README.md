## Features
- `/start` random cute banners
- `/pinterest` / `/pin` — 10 Pinterest photos
- `/tmdb` — movie / series search
- `/ping` `/stats` `/id` `/help`
- Group helpers

## Deploy
```bash
pip install -U -r requirements.txt
cp sample.env .env
# fill .env
python3 -m Cyra
```

Heroku: set config vars from `sample.env` then deploy.
